# Заимствование исходника в Rust-порте (локальная копия)

Оригинальный Rust-порт (`fasthtmlparser` 0.1.0) владеет строкой: `Document::parse(impl
Into<String>)` всегда копирует `&str` в `String`. C++-порт умеет и заимствовать
(`parse_borrowed`), и владеть, поэтому для честного сравнения в локальную копию
`ref/rust` был добавлен заимствующий режим. Апстрим не менялся.

## Что изменено

- `Document<'src> { source: Cow<'src, str>, .. }`; `Node<'a> { doc: &'a Document<'a> }`.
- `parse`, `parse_bytes`, `parse_with_url` остались в `impl Document<'static>` и владеют
  строкой.
- Добавлен `pub fn parse_borrowed(source: &'src str) -> Document<'src>`.
- Механические правки сигнатур в `css.rs`, `xpath.rs`, `shortcuts.rs` (lifetime у
  `Document`), в `attributes.rs` — `source.as_ref()` вместо `String::as_str`.
- В бенчмарке `bench/src/main.rs` появился `make_doc`: по умолчанию заимствует,
  `FH_BENCH_COPY=1` возвращает владеющий режим для A/B в одном процессе.

Тесты и `--check` проходят: записи скрапинга совпадают с остальными библиотеками.

## Замеры (books, 556 тегов, один процесс, 2 прогона)

| | владение | заимствование |
|---|---:|---:|
| разбор books 51 КБ | 42.2 µs | **42.0 µs** |
| разбор books ×10 | 434 µs | **423 µs** |
| Find / CSS / XPath | 56.0 / 58.5 / 86.8 | **53.5 / 56.1 / 84.0** |

Отдельный микрозамер только парсинга: 42.0 против 41.2 µs. То есть копия 51 КБ стоит
около 1 µs, а `Cow` добавляет незначительную нагрузку на доступах к исходнику; суммарно
заимствование экономит 1–4%. Оставляем его ради эквивалентности с C++.

С PGO (профиль сгенерирован на заимствующей сборке) Rust показывает books 35.2 µs,
×10 356 µs, Find/CSS/XPath 45.0 / 47.5 / 65.9 µs — та же картина, что и у C++:
PGO снимает около 13–15%.
